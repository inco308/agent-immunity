# 真实 LLM 评测快照

本次为脱敏占位误报修复后的新评测。查看[完整前后比较](comparison/README.md)、[修复与安全回归说明](../../../docs/redaction-fix.md)及[历史调用离线重判](regression-replay.json)。离线重判不计入下面的真实模型样本。

这是固定小样本上的实际模型轨迹。基线与网关分别重新规划，样本分母不能解释为总体安全率。
所有输入、canary 和服务均为评测自建；没有真实凭证。原始轨迹、判据、用量和代码摘要在各 JSON 中。

B/G 分别表示无网关基线和网关。条件拦截率只有发生实际攻击调用时才有定义；模型没有尝试攻击不算网关拦截。
合法调用误报分母包含攻击场景里的正常业务动作，不能用纯正常任务的零误拒绝掩盖脱敏报告的误报。
任务产物成功和攻击成功独立记录；拦截成功也不保证模型能够恢复正常任务。

结果按实际轨迹记录；误报、任务失败与攻击成功均保留，修复前后对比须同时核对模型和输入配置。
每个 case/模式只运行一个样本；Codex/dsh 不支持此评测的采样 seed，厂商系统提示与工具封装也不同，不能作为纯模型公平排名。
每次调用返回后采样文件树，仍无法看到恶意工具在一次调用内部完成写入再完全恢复的行为。

源 Git 基线是特性提交前的 HEAD，实际运行代码与数据由 JSON 中的逐文件 SHA256 标识。
publication.normalized_lf_source_sha256 另提供统一 LF 行尾的源码摘要，便于与 Git 内容核对；运行时字节摘要仍原样保留。
手动 CI 的 4B 模型仅运行三场景 CPU 子集，报告在 Actions artifact 中，必须与这里的本地八场景/云端 CLI 结果分开解读。

额外后端的探测与隔离情况见 [可用性记录](availability.json)；可用性探测不等于已经完成同一数据集评测。
